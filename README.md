# Nina — IVF Journal

A gentle, feminine IVF companion for day-by-day journaling, feelings, symptoms, gratitude, and private letters.

## What is included

- Daily IVF journal entries with treatment phase and cycle day
- Feeling check-ins: soft, hopeful, heavy, anxious, grateful, tender
- Energy tracking from 1–10
- Body notes, heart notes, gratitude, and private letter prompts
- Recent-entry timeline
- Local-only privacy model for the MVP
- JSON export for future backup, migration, or paid-account import
- Mobile-first soft visual design using Nina's image

## Why it matters commercially

This starts as a personal, emotionally safe journal, but can become a commercial IVF companion app with:

1. Private cloud sync and account recovery
2. Partner mode for shared updates
3. Clinic appointment and medication reminders
4. PDF export for doctor appointments
5. Paid premium journaling packs and guided prompts
6. Anonymous emotional trend insights
7. Multi-language support for FR / EN / AR

The current MVP stores entries in browser localStorage only. Before commercialising, add clear privacy policy, consent, encryption strategy, data export/delete, and health-data compliance review.
